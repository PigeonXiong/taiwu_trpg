# 刀法催破

元山派催破招式

刀法催破

八卦五行刀

八卦五行刀共有六十四式，行刀之际，脚踩八卦宫阵，刀藏五行变化，步随刀转，刀随步变，连绵不断，滔滔不竭。

等级： 1

类型： 元山派 \ 催破 · 刀 法 \ 仪式

属性： 归元

需求： 刀法1，膂力2

运功效果：

拆招 +1 。

施展： 仪式动作，12先机

消耗： 2架势，1 撩 式

触及： +1

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「刀法」攻击。命中任意一项额外造成1d6伤害。命中至少两项时，对目标造成1个破绽。

心法正练：本招式每命中一项，就能偷取目标1个「 撩 」式。

心法逆练：施展本招式且全部命中时，偷取目标所有「 撩 」式 。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的 拆招 再+1。

六合刀法

六合刀法乃是应地支六合之变化而创，守也坚固，攻也刚强，有如诀曰：“守似午未合化土，柔里带刚强且韧；攻如辰酉合化金，风雷骤起祸横生”。

等级： 2

类型： 元山派 \ 催破 · 刀 法 \ 仪式

属性： 混元

需求： 刀法2，膂力3，根骨2，灵敏2

运功效果：

卸力 +1 。

施展： 仪式动作，13先机

消耗： 2架势，2 撩 式

触及： +1

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「刀法」攻击。命中任意一项额外造成 1d6伤害。命中至少两项时，对目标造成1个破绽。

心法正练：施展本招式且命中时，记录命中的项数为X。本招式结算完成后，你能立刻无需动作地进行X次连续的【收刀】或【拔刀】。

心法逆练：本招式每命中一项，你便能无需动作地对目标尝试一次任意类型的「刀法」普通攻击。这次攻击不会造成伤害，但在命中或擦伤时能够将目标一件手持的物品击落在他的脚下，每获得1个净成功就能将物品朝一个方向多击飞1格。目标需要以【简单动作

· 准备物品】来捡起自己威胁范围内的物品。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的 卸力 再+1。

虎步八极刀

正所谓：“九州之外有八寅，八寅之外有八纮，八纮之外有八极”。虎步八极刀大开大阖，劲走十字，沉堕刚猛，刀势可达四面八极。

· 15先机】来无消耗地施展本招式的机会。这个机会不能保留至下一轮。施展本招式后，你获得异常状态：持续2轮，无法获取「藏剑」。

心法逆练：你成功施展任何「催破

·

剑法」且有至少一项未命中时，你获得增益效果：持续至战斗结束，本招式的额外破体+1、命中骰池也获得+1加值。这个增益效果能不断累积，最高加值不超过你的刀法等级。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的 卸力 再+1。

太乙金刀

太乙金刀混沉自然，一气呵成，意合阴阳五行，身走奇门遁甲，刀力既强，变化亦精，人谓之道门刀法之“金华”也。。

\ 破气2

心法正练：当你运起本功法时，你能在施展其他催破招式时，额外消耗X层「匿刀」或「藏剑」。若如此做，该次催破招式的命中骰池、额外破体、额外破气均会

[+2X] 。

七星刀法

七星刀法共有一百九十六式，与北斗七星在四时当中的诸般变化一一对应，此刀法深沉刚勇，法度严谨，行刀迅若流星，应变奇速。

[+Yd6] 。

无极刀法

无极刀法式无常势，刀无常形，心无常念，神无常主，精微玄奥，慧勇无边，有道是：“法无尽，用无穷，无限，无终，以为无极”。

类型： 元山派 \ 催破 · 刀 法 \ 仪式

属性： 混元

需求： 刀法6，悟性5，膂力4

运功效果：

施展： 仪式动作，12先机

消耗： 4提气，2 劈 式+2 撩 式

心法正练：成功施展本招式且两项攻击全部命中时，你获得增益状态：持续到战斗结束，你能将1点每轮获取的架势转换为1点提气。这个状态可以至多叠加5次，每叠加1次便能多转换1点架势。

心法逆练：本招式的消耗和伤害分布将不会受到内伤发挥的影响。本招式成功施展完毕后（未命中、丢失目标也计入），你获得与本招式所消耗提气等量的架势。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的 卸力 再+1 、御气再+1。

天罡刀法

“罡者四正为罡，取四方之正中，居於天中之天，乃阳精真土也”。天罡刀法赫赫有威，神通广大，乃道门法刀之绝诣，玄门大道之不二正法也。
