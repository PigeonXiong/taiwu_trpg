# 身法_催破

无门无派招式

身法

小纵跃功

小纵跃功乃是以连续的纵跃快速行动的粗浅轻功，虽然修习门法十分简单，但修习过程极长，非数十年寒暑不能练就，故而功法虽简，修习者却聊聊无几。

等级： 1

类型： 无门无派 \ 身法

属性： 混元

需求： 定力2

运功效果：

无

施展： 简单动作，5先机

消耗： 1移动力，1架势 /

提气

额外移动： 1次周旋

施展效果：

施展此身法时，可进行 [灵敏+身法] 检定，若得到2个或更多成功，则以简单动作使用本身法提供的周旋时，能移动2格（通常，周旋只能移动1格）。

心法正练：上述检定自动成功，但2个格子必须为连续的直线，且都须用来靠近敌人。

心法逆练：上述检定自动成功，但2个格子必须为连续的直线，且都须用来远离敌人。

心法冲解：无变化。

催破

太祖长拳

太祖长拳共有三十二式，朴实无华，简单存粹，虽然招式粗浅，却已含拳术至理，故而人称“百拳之母”。

等级： 1

类型： 无门无派 \ 催破 · 拳法 \ 仪式

属性： 混元

需求： 拳掌1，膂力2

运功效果：

拳掌相关检定骰池 +1 。

施展： 仪式动作，10先机

消耗： 2架势、1崩式

触及： +3

目标： 单体

伤害： 武器伤害+1~3d6，无额外穿透

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「拳掌」攻击。每命中一项额外造成1d6伤害。命中至少2项时，你对目标造成一个破绽。

心法正练：本功法的三项命中骰池均+2。

心法逆练：若你在一场切磋中恰好以太祖长拳击败了敌人，可以在战斗结束后如交涉成功般向对方提出一个要求。

心法冲解：净成功能造成额外伤害。运功时，徒手和掌套的武器伤害+1。

三十六路擒拿手

暂缺

等级： 2

类型： 无门无派 \ 催破 · 拳法 \ 仪式

属性： 归元

需求： 拳掌3，悟性2，灵敏2

运功效果：

徒手和掌套的武器伤害 +1， 精妙 类攻击骰池+2。

施展： 仪式动作，15先机

消耗： 2架势、1提气、1崩式+1拿式

触及： +2

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -1

施展效果：

你进行一次 力道 + 精妙 的复合「拳掌」攻击。 力道 命中 额外造成2d6伤害， 精妙 命中 额外造成1d6伤害。2项全部命中时，擒拿目标。

心法正练： 精妙 项命中即可擒拿目标。

心法逆练：只要你保持着擒拿，每战斗轮1次，你能在受到攻击（对方投掷检定前）时，以【反应

· 10先机】让你的被擒者来承受此攻击。

心法冲解：净成功能造成额外伤害。运功时 力道 类 攻击骰池+1。
