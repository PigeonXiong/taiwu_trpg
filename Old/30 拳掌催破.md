# 拳掌催破

少林派催破招式

拳掌

少林长拳

少林长拳讲究“筋顺骨直，正大光明”，招式尽是横截直击，虽然看似简单刻板，然而法度却极严谨，堪称少林武学之典范。

等级： 1

类型： 少林派 \ 催破 · 拳法 \ 仪式

属性： 金刚

需求： 拳掌1，膂力2

运功效果：

力道 、 精妙 类攻击 骰池+1 。

施展： 仪式动作，10先机

消耗： 2架势，1 崩 式

触及： +2

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「拳掌」攻击。每命中一项额外造成1d6伤害。命中至少2项时，对目标造成一个破绽。

心法正练：在每场独立的战斗中，每成功施展一次本招式（未命中、丢失目标也计入），其他「少林派」拳掌催破招式的伤害就累计+1d6。

心法逆练：在每场独立的战斗中，每成功施展一次其他「少林派」拳掌催破招式（未命中、丢失目标也计入），此功法的伤害就累计+2d6。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的骰池加值再+1。

少林金刚掌

少林金刚掌易学难精，虽初练即生开碑碎石之刚强掌力，然而若要练至阳劲内敛而生阴劲乃至刚柔相济的上乘境界，却极是艰难。

等级： 2

类型： 少林派 \ 催破 · 拳法 \ 仪式

属性： 金刚

需求： 拳掌2，定力2，膂力2

运功效果：

力道 类攻击 骰池+2，徒手和掌套的武器伤害+1 。

施展： 仪式动作，12先机

消耗： 2架势，2 崩 式

触及： +1

目标： 单体

伤害： 武器伤害+1~4d6，额外破体1

内伤发挥： -2

施展效果：

你进行一次 力道 + 精妙 的复合「拳掌」攻击。命中 力道 额外 造成3d6伤害、命中 精妙 额外 造成1d6伤害。

心法正练：施展本招式且命中后，下次拳掌功法若全部造成外伤，则最终伤害+Xd6，X为本招式获得的净成功。

心法逆练：施展本招式且命中后，下次拳掌功法若全部造成外伤，则三项命中+X，X为本招式获得的净成功。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的武器伤害再+1。

大通臂拳

“其起如虎扑人，其落如鹰捉物”，力贯双臂，左右一体，谓之“通臂”也。大通臂拳招式刚猛，直上直下，放长而击远，势整而力顺。

等级： 3

类型： 少林派 \ 催破 · 拳法 \ 仪式

属性： 金刚

需求： 拳掌3，定力2，体魄3

运功效果：

拳掌等级 +1 。

施展： 仪式动作，10先机

消耗： 3 架 势，1 崩 式+1 拿 式

触及： +4

目标： 单体

伤害： 武器伤害+2~4d6，额外破体3

内伤发挥： -3

施展效果：

你进行一次 力道 + 精妙 的复合「拳掌」攻击。命中 力道 额外 造成2d6伤害、命中 精妙 额外 造成2d6伤害。

心法正练：你使用「武艺

· 拳掌」进行普通攻击时，触及从「短」变更为「短+中」。

心法逆练：你的拳掌武器伤害+4，但拳掌类普通攻击和招式因为触及不足而产生的减值由-4提升至-6。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功时徒手和掌套的武器伤害+1。

六十八式罗汉拳

大金刚拳

大金刚拳刚猛绝伦，力发千斤，拳力稳重果决，气势雄浑，招式大开大合，井然不失法度，举手投足间均显示出莫大的威力。

等级： 5

类型： 少林派 \ 催破 · 拳法 \ 仪式

属性： 金刚

需求： 拳掌5，膂力3，体魄3

运功效果：

力道 类攻击 骰池+3 。拳掌相关检定骰池+1。

施展： 仪式动作，13先机

消耗： 4 架 势，3 崩 式

触及： +1

目标： 单体

伤害： 武器伤害+1~7d6，额外破体6

内伤发挥： -4

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「拳掌」攻击。命中 力道 额外 造成5d6伤害、命中 迅疾 或 精妙 额外 造成1d6伤害。

心法正练：施展本招式且三项攻击全部命中时，你获得增益状态：持续至战斗结束，你的护体与御气增加2点，本增益可以叠加。

心法逆练：施展本招式且三项攻击全部命中时，你获得增益状态：持续至战斗结束，目标的护体与御气减少2点，本增益可以叠加。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的 力道 加值再+2。

达摩十八手

所谓：“达摩西来一字无，全凭心意用功夫”，达摩十八手招式固然精奇，而那“守心住缘，无念为宗”的功法总诀更为少林武学之真髓。

等级： 6

类型： 少林派 \ 催破 · 拳法 \ 仪式

属性： 金刚

需求： 拳掌5，定力5，体魄3

运功效果：

精妙 类攻击 骰池+3，拳掌等级+1 。

施展： 仪式动作，11先机

消耗： 2 架 势，2提气，2 崩 式+1 点 式+1 拿 式

触及： +2

目标： 单体

伤害： 武器伤害+2~6d6，额外破体4

\ 破气4

内伤发挥： 0

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「拳掌」攻击。每命中一项额 外 造成2d6伤害。命中至少2项时，对目标造成一个破绽和一个点穴。

心法正练：本招式成功施展完毕后（未命中、丢失目标也计入），你获得增益状态：直到你施展完毕下一个催破招式，将你的护体值加在你的破体上。

心法逆练：本招式成功施展完毕后（未命中、丢失目标也计入），你获得增益状态：直到你施展完毕下一个催破招式，将你的御气值加在你的破气上。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6。运功提供的拳掌等级再+1。

金刚般若掌

金刚般若掌刚强无俦，由外而内，内外兼修，威力奇大无比。掌力一旦吐出便汹涌难绝，层层叠叠，莫可抵挡，堪称少林第一神掌。

类型： 少林派 \ 催破 · 拳法 \ 仪式

属性： 金刚

需求： 拳掌7，定力3，体魄3，膂力3

运功效果：

力道 类攻击 骰池+5 。膂力相关检定骰池+1。

施展： 仪式动作，14先机

消耗： 4 架 势，1提气，4 崩 式

触及： +1

目标： 单体

伤害： 武器伤害+3~8d6，额外破体6

内伤发挥： -3

施展效果：

你进行一次 力道 + 精妙 的复合「拳掌」攻击。命中 力道 额外 造成5d6伤害、命中 精妙 额外 造成3d6伤害。

心法正练：施展本招式且两项攻击全部命中时，清除目标身上的所有增益状态，清除目标现有的身法额外移动。

心法逆练：施展本招式且两项攻击全部命中时，目标获得异常状态：持续至战斗结束，破体、破气、护体、御气全部置为0，每轮获取的移动力置为1。目标仍能通过后续获得的增益状态来提升这些数值。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6。运功提供的 力道 加值再+2。

降魔光明拳

“愿我智慧光，普照十方刹”。降魔光明拳质朴温和，却具无上大力，招式举重若轻，劲力无所不至，正如佛光普照一切时，一切处。

类型： 少林派 \ 催破 · 拳法 \ 仪式

属性： 金刚

需求： 拳掌7，定力7，膂力3，悟性3

运功效果：

力道 类攻击 骰池+2， 精妙 类攻击 骰池+3，拳掌等级+1 。

施展： 仪式动作，15先机

消耗： 1 架 势，4提气，4 崩 式

触及： 无

目标： 所有距离0~1格的敌人

伤害： 武器伤害+5~10d6，额外破体4

\ 破气8

内伤发挥： +3

施展效果：

你进行一次 力道 + 精妙 的复合「拳掌」攻击。命中 任意一项额外 造成5d6伤害。此外，以1~5分别代表刚正、仁善、中庸、叛逆、唯我，并以此计算你与目标间的阵营之差的绝对值，设为X。

心法正练：本招式只能造成非致命伤害，若你的阵营为仁善，则该功法的命中检定骰池+X、触及+X、最终伤害+[2Xd6]；施展本招式且两项攻击全部命中时，目标的阵营会向仁善变化1级。

心法逆练：本招式只能造成致命伤害，若你的阵营为叛逆，则该功法的命中检定骰池+X、触及+X、最终伤害+[2Xd6]；施展本招式且两项攻击全部命中时，目标的阵营会向叛逆变化1级。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6。运功提供的骰池加值再+2。
