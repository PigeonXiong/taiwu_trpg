# 长兵催破

少林派催破招式

长兵

少林六合棍

少林六合棍招式明快，不简不繁，尚直取快攻而忌游移不定，出棍讲究“内三合”与“外三合”、内外相合、六合相合，故名“六合棍”。

等级： 1

类型： 少林派 \ 催破 · 长兵 \ 仪式

属性： 混元

需求： 长兵1，膂力2

运功效果：

精妙 类攻击 骰池+1 。

施展： 仪式动作，10先机

消耗： 2架势，1 撩 式

触及： +2

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「长兵」攻击。每命中一项额外造成1d6伤害。命中至少2项时，对目标造成一个破绽。

心法正练：每命中一项，你便可以选择1项增益状态获得：持续到自己施放下一个护体绝技，该护体绝技减少1点架势消耗/减少3点先机消耗/持续时间增加1轮。若在施放护体绝技前再次施放了本催破，则需要选择不同的增益状态。

心法逆练：当敌人触发你的反击时，你能以【反应

· 10先机】来施展本招式，以取代通常的反击。你仍要支付2架势，1撩式的正常消耗。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的骰池加值再+1。

少林阴阳棍

所谓“阴阳棍”，乃是由于此棍法分为内与外、上与下、骑与步两组招式，两组招式既可分使，亦可高低并用，上下齐施。

等级： 2

类型： 少林派 \ 催破 · 长兵 \ 仪式

属性： 金刚

需求： 长兵2，膂力3，灵敏3

运功效果：

长兵等级+1 。

施展： 仪式动作，10先机

消耗： 2架势，1提气，2 撩 式

触及： +2

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合 「长兵」攻击。每命中一项额外造成1d6伤害

心法正练：施展本招式后（未命中、丢失目标也计入），你获得增益状态：直到施展下个催破功法前，你可以将所有获得的劈、刺式变为撩式。

心法逆练：每命中一段，你获得1个撩式。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供御气+1。

十八点齐眉棍

十八点齐眉棍讲究：“乱棍猛击，棍打群敌”，既可于一招之间分袭一十八个敌人，也能同时将一十八次棍击施于同一敌人之身。

等级： 3

类型： 少林派 \ 催破 · 长兵 \ 仪式

属性： 混元

需求： 长兵3，膂力2，体魄2，灵敏2

运功效果：

精妙 类攻击 骰池+2。护体+1。

施展： 仪式动作，10先机

消耗： 3 架 势，2 撩 式

触及： 无

目标： 所有距离2格的敌人

伤害： 武器伤害+1~3d6，额外破体3

内伤发挥： -3

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合 「长兵」攻击。每命中一项额外造成1d6伤害，命中至少两项时对目标造成1个破绽。

心法正练：当本招式的目标仅有1人，且成功命中并造成破绽时，你每有2个撩式（不包含本招式消耗的撩式），便能额外再造成1个破绽。

心法逆练：当本招式的目标仅有1人，且成功命中并造成破绽时，你可以消耗现有的所有撩式（不包含本招式消耗的撩式），额外再造成相同数量的破绽。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的 骰池加值再 +1。

大小夜叉棍

大小夜叉棍既可放长击远，亦可近身入怀，且多有逆挑、疾点、猛戳等凌厉绝技，正是“三分棍法七分枪法”，长短兼用，亦棍亦枪。

等级： 4

类型： 少林派 \ 催破 · 长兵 \ 仪式

属性： 金刚

需求： 长兵3，膂力3，灵敏3，定力2

运功效果：

所有长兵类检定的 骰池+2 。

施展： 仪式动作，10先机

消耗： 3 架 势，1 劈 式+1 刺 式+1 撩 式

触及： +3

目标： 单体

伤害： 武器伤害+1~3d6，额外破体3

内伤发挥： -3

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「长兵」攻击。每命中一项额 外 造成1d6伤害。

心法正练：你能以-4的骰池减值将短触及的敌人选作本招式的目标，如同你手中的长兵武器是中触及一般。这样做且成功命中后，本招式的总伤害还会增加3d6。

心法逆练：你能不受骰池减值地，将距离3格的敌人选作本招式的目标。这样做且成功命中后，本招式的总伤害还会增加3d6。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的骰池加值再+1。

五虎群羊棍

五虎群羊棍法度严密，气势宏大，运棍之时全身着力，上下左右一体，俯仰进退皆可攻敌，兼之棍力刚猛，临敌直如虎入羊群，威不可当。

心法逆练：若你在任意护体绝技生效期间施展本招式，则本招式的架势提气消耗均减少为1，并且你的三项防御值、护体御气均+1。

少林疯魔棍

少林疯魔棍横扫东南西北，恶劈四面八方，凶猛巧健，捅天打地，为避其不尊天地方位之忌，故而取名“疯魔”，是以并无半点“疯颠”之态。

韦陀降魔杖

韦陀降魔杖刚勇强劲，沉雄无比，杖力笼罩之下，处处皆是无形罡气，攻可摧邪辅正，除魔卫道，守亦坚固不破，固若金汤。

达摩杖法

有道是：“棍乃百兵之祖”，达摩杖法更是一切棍术杖法之先师鼻祖。达摩杖法共有四十八式，乃达摩祖师之真传绝艺，其法精奇古朴，神乎其神。

属性： 混元

\ 破气6
