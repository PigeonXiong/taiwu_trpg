# 剑法催破

元山派催破招式

剑法催破

罗汉剑法

罗汉剑法刚直不屈，法度严谨，行剑沉稳有力，招式极少转折，每次出剑必先取守势，乃是以守为攻，四平八稳的佛门剑术。

等级： 1

类型： 元山派 \ 催破 · 剑 法 \ 仪式

属性： 归元

需求： 剑法1，体魄2

运功效果：

力道 类攻击 骰池+1 。护体+1。

施展： 仪式动作，10先机

消耗： 2架势，1 劈 式

触及： +1

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中任意一项额外造成1d6伤害。

心法正练：施展本招式且命中后，记命中了X项，你恢复Xd6点外伤。

心法逆练：施展本招式且命中后，记命中了X项，你恢复Xd6点内伤。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的骰池加值再+1。

普渡剑法

普度剑法共有十式，分别指向周身四面共十个不同的方位，剑势中正平和，只去不回，此乃：“剑发十方，普度众生”之意。

等级： 2

类型： 元山派 \ 催破 · 剑 法 \ 仪式

属性： 混元

需求： 剑法2，定力3，膂力2，体魄2

运功效果：

力道 、 精妙 类攻击 骰池+2 。

施展： 仪式动作，10先机

消耗： 2架势，2 劈 式

触及： +2

目标： 单体

伤害： 武器伤害+1~3d6，额外破体2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中任意一项额外造成 1d6伤害。命中至少两项时，对目标造成1个破绽。

心法正练：施展本招式且命中时，目标获得负面效果：持续3轮，目标若处于相枢化魔，则他只会获得与相枢入魔相同的好处；若目标处于相枢入魔，则不会获得其好处。若你恰好以本招式击败敌人，则减少目标入魔值2点。

心法逆练：施展本招式且命中时，目标的入魔值减少1点。若你恰好以本招式击败敌人，则清空目标入魔值。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的骰池加值再+1。

七十二嗔剑

七十二嗔剑极其刚猛，不仅行剑直上直下，如使单刀，而且每一式剑招均有一声呵斥怒号与之相和，其声势直如雷嗔电怒，尤其惊人。

等级： 3

类型： 元山派 \ 催破 · 剑 法 \ 仪式

属性： 归元

需求： 剑法3，体魄3，灵敏2，定力2

运功效果：

力道 类攻击 骰池+3 。

施展： 仪式动作，8先机

消耗： 3架势，2 刺 式

触及： +1

目标： 单体

伤害： 武器伤害+1~5d6，额外破体1

内伤发挥： -3

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 力道 或 迅疾 额外 造成2d6伤害、命中 精妙 额外 造成1d6伤害。

心法正练：本招式无法正常施放，当你拔出一把剑类武器时，你能消耗1层「匿刀」，获得一次以【复合动作

· 15先机】来无消耗地施展本招式的机会。这个机会不能保留至下一轮。施展本招式后，你获得异常状态：持续2轮，无法获取「匿刀」。

心法逆练：你成功施展任何「催破

·

刀法」且有至少一项未命中时，你获得增益效果：持续至战斗结束，本招式的额外破体+1、命中骰池也获得+1加值。这个增益效果能不断累积，最高加值不超过你的剑法等级。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的骰池加值再+1。

大慈悲剑

“大慈与一切众生乐，大悲拔一切众生苦”。大慈悲剑法度森严，常无懈倦，看似御敌实为律己，剑力因敌而异，敌势越恶，威力越强。

等级： 4

类型： 元山派 \ 催破 · 剑 法 \ 仪式

属性： 归元

需求： 剑法4，膂力3，根骨3，定力2

运功效果：

剑法等级+1 。 精妙 类攻击 骰池+1 。护体+1。

施展： 仪式动作，10先机

消耗： 2 架 势，1提气，3 劈 式

触及： +1

目标： 单体

伤害： 武器伤害+1~5d6，额外破体3

\ 破气3

内伤发挥： -1

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 力道 或 迅疾 额外 造成1d6伤害、命中 精妙 额外 造成3d6伤害 。至少命中两项时，对目标造成1个破绽。

心法正练：施展本招式且命中时，记你此时所受外伤为X，你恢复

[X/4] 点外伤。若三项全部命中，恢复量提升至 [X/2] 。

心法逆练：施展本招式且命中时，记目标此时所受外伤为X，本招式的总伤害+[X/4]。若三项全部命中，伤害提升至

[X/2] 。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的骰池加值再+1，且护体再+1。

文殊大智慧剑

文殊大智慧剑共有五式，每式皆有五百小变化，五十大变化，所有变化既可分使，又可合而为一，极其深奥，纵有超凡智能者亦不能穷其奥妙。

等级： 5

类型： 元山派 \ 催破 · 剑 法 \ 仪式

属性： 归元

需求： 剑法5，定力4，悟性3

运功效果：

力道 类攻击 骰池+2、 精妙 类攻击 骰池+3 。

施展： 仪式动作，12先机

消耗： 1 架 势，3提气，1 劈 式+2 刺 式

触及： +1

目标： 单体

伤害： 武器伤害+2~7d6，额外破体2

\ 破气4

内伤发挥： +2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 力道 或 迅疾 额外 造成2d6伤害、命中 精妙 额外 造成3d6伤害。至少命中两项时，对目标造成1个点穴。

心法正练：施展本招式且成功造成点穴时，对目标造成异常状态：持续到战斗结束，破体和破气均-2。这个异常状态可以累积。当目标的破体或破气因此降低至0或更低时，本招式不再添加该状态，但命中后的总伤害会增加5d6。

心法逆练：施展本招式且成功造成点穴时，对目标造成异常状态：持续到战斗结束，护体和御气均-2。这个异常状态可以累积。当目标的破体或破气因此降低至0或更低时，本招式不再添加该状态，但命中后的总伤害会增加5d6。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的 力道 类攻击 骰池再+1、 精妙 类攻击 骰池 再+2。

韦陀伏魔剑

韦驮伏魔剑迅疾刚勇，剑出有金光，可瞬间击出数十丈之远，其威势之坚强，好似韦驮天手持宝杵以镇群魔，凛然不可侵犯，绝无消退移转。

等级： 6

类型： 元山派 \ 催破 · 剑 法 \ 仪式

属性： 归元

需求： 剑法6，膂力4，灵敏4

运功效果：

力道 类攻击 骰池+2、 迅疾 类攻击 骰池+4。护体+2。

施展： 仪式动作，11先机

消耗： 4架势，2 劈 式+2 刺 式

触及： +3

目标： 单体

伤害： 武器伤害+4~8d6，额外破体7

\ 破气1

内伤发挥： -4

施展效果：

你进行一次 力道 + 迅疾 的复合「剑法」攻击。命中任意一项 额外 造成4d6伤害。命中至少一项，对目标造成一个破绽。

心法正练：成功施展本招式且两项攻击全部命中时，你获得增益状态：持续到战斗结束，你能将1点每轮获取的提气转换为1点架势。这个状态可以至多叠加5次，每叠加1次便能多转换1点提气。

心法逆练：本招式的消耗和伤害分布将不会受到内伤发挥的影响。本招式成功施展完毕后（未命中、丢失目标也计入），你获得与本招式所消耗架势等量的提气。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的 力道 类 骰池再+1、 迅疾 类 骰池 再+2、护体再+1。

无上菩提剑

无上菩提剑质朴平和，清澈明净，剑不生疲惓，常化诸妄法，其体广大，其德无边，犹如诸佛无上究竟之正觉，乃佛门剑法之真髓正果也。

等级： 7

类型： 元山派 \ 催破 · 剑法 \ 仪式

属性： 混元

需求： 剑法6，膂力4，悟性4，定力4

运功效果：

精妙 类攻击 骰池+7 。

施展： 仪式动作，12先机

消耗： 3 架 势，2提气，2 刺 式+2 撩 式

触及： +1

目标： 单体

伤害： 武器伤害+2~8d6，额外破体6

\ 破气6

内伤发挥： -1

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合 「剑法」攻击。命中 力道 或 迅疾 额外造成2d6伤害，命中 精妙 额外造成4d6伤害。命中至少两项，对目标造成一个破绽。

心法正练：特别的，你能消耗2层「匿刀」，以【复杂动作

· 10先机】来无消耗地施展本招式，以此法施展的本招式必须使用剑类武器。以此法施展本招式后，你获得异常状态：持续2轮，无法获取「匿刀」。

心法逆练：成功施展本招式且命中至少两项时，造成的破绽由1个增加为3个。此外，本招式所产生的破绽，在战斗结束前无法被任何方式移除。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6。运功提供的骰池加值再+3。

达摩剑法

达摩剑法正大不阿，既有刚勇强直之伏魔正法，亦不失神妙精微之奇绝变化，正是：“身入禅定无想无念，剑走玄机十方圆明”。

等级： 8

类型： 元山派 \ 催破 · 剑 法 \ 仪式

属性： 归元

需求： 剑法7，定力6，膂力5

运功效果：

剑法相关 骰池检定+2 。剑法等级+1。护体+2。

施展： 仪式动作，12先机

消耗： 4架势，1提气，2 劈 式+1 刺 式+2 撩 式

触及： 无

目标： 威胁范围内的单体敌人

伤害： 武器伤害+3~9d6，额外破体8

/ 破气6

内伤发挥： -3

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 任意一项额外 造成3d6伤害。命中至少一项，对目标造成1个破绽。

心法正练：成功施展本招式并选择目标后，你能再清空自己的架势（在支付本招式的架势消耗之后），记被额外消耗的架势为X点。本招式的命中检定+X，最终伤害+[Xd6]，额外破体、破气均+X。

心法逆练：成功施展本招式并选择目标后，你能再清空自己的架势（在支付本招式的架势消耗之后），记被额外消耗的架势为X点。你恢复

[Xd6] 点外伤。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6，且剑法相关骰池再+1、护体再+1。
