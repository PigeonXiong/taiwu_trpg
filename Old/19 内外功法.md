# 内外功法

功法

功法分为【内功心法】和【外功招式】。而外功招式又分为【催破招式】、【身法】、【绝技】三大类别。

内功心法能为角色提供内力等大量基础属性，催破招式能消耗式、架势、提气等资源来进行强力的攻击，身法能帮助角色的移动，而绝技则可以增强角色的防御并提供各具特色的战斗能力。

修习与运功

修习：

玩家能在创建角色时通过对应的点数来修习内功心法和外功招式，也能在冒险开始后消耗时间和造化修习它们。详见“创建角色”和“人物提升”章节。要修习任何功法，角色的属性和武艺技艺等于要需要满足其需求，并且有合适的导师（门派前辈、师父、秘籍等等）。

内功心法的修习总数是有限的，外功招式则无限。但 同一时刻一个角色可【运功】的内功心法和外功招式都是有限的。任何内功心法和外功招式的主动效果，都需要被运功后才能使用。

内功心法修习上限 =

根骨（ 所有等级的心法均视为1个修习数）

外功招式修习上限 = 无限

运起内功心法：

内功心法只要被修习完成，就能为角色提供各属性的内力，并提高角色的基础HP和真气上限；同时，它们在被运功时也有额外的被动效果。无论角色的「武艺·内功」为多少，他总能运功1个内功心法。这个内功心法称为【主运心法】，角色可以选择任意等级的、已修习完的心法作为他的主运心法。在主运心法外，角色还能运功数量有限的【副运心法】，副运栏位受限于角色的武艺·内功等级，且越高级的功法占据越多的栏位。

副运心法栏位 =

「武艺·内功 」 等级/3（向上取整）

1~3级心法占据1栏、4~6级心法占据2栏、7~9级心法占据3栏

运起外功招式：

外功招式在被修习后不会带来好处，需要运功才能产生被动效果。外功招式的运功数量由角色的体魄属性决定，且主运心法能提供额外的数量。注意和内功心法不同，外功招式无论等级，只会占据1个栏位。通用招式能用来运起任意外功招式，而催破栏位、身法栏位、绝技栏位则只能运功对应外功招式。

外功招式通用栏位 = 体魄 + 主运心法提供的额外通用栏位

外功招式催破栏位 = 主运心法提供的额外催破栏位

外功招式身法栏位 = 主运心法提供的额外身法栏位

外功招式绝技栏位 = 主运心法提供的额外绝技栏位

所有等级的外功招式均占据1栏

经过一次长休后，角色可以更换他当前运功的内功心法和外功招式。

正练、逆练、冲解

当角色修习新的功法时，他需要选择以正练、逆练还是冲解的形式来获得这些功法。正练和逆练意味着不同的特殊效果，而冲解则是放弃所有特殊效果，以求功法提供更多的基础属性。

这项选择不能轻易改变，角色需要花费2点造化与修习这个功法相同的时间来更改最初的选择。
