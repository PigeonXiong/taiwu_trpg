# 勤学苦练

获得造化

我们用【造化】来表示角色在冒险中获得的经验与历练，这项资源可以被用来提升基本属性、提升技能等级、修习新的功法。这也是太吾世界中的人物锻炼自己的主要方式。

以一次现实时间3~4小时的线下短团（线上团可能耗时翻倍）为例，大约包含3个非战斗难题、1~2次简单战斗、1次困难战斗。一般地，完成这样一次团能让PC每人获得6点造化，根据任务目标的达成度还能再增加1~2点。

GM也应当以额外造化来奖励那些呈现了有趣扮演或机智选择的玩家，但应保持所有玩家在一次冒险中获得的造化差在20%以内。

对于长团来说，GM可以按照上述方式估算造化，也可将故事切分作多个结点，并在到达结点时给予玩家合适的造化。此外，在长团中，GM也应当为玩家们提供足够的故事内时间以供角色提升。

消耗造化

角色们能参考下表消耗造化，获取新的能力。需要注意，任何一项升级除了消耗造化以外，还应当消耗故事内的时间，也就是说，只有当GM给予足够长的休整期时，角色才能不受干扰地专心锻炼自己。

提升技能·技艺： 消耗 [1] 点造化，进行长达 [目标等级 x 半月] 的学习，来让某项技艺提升1级。目标等级在4点及以上时，消耗的造化和时间会x2；目标等级在7点及以上时，消耗的造化和时间会x4。在创建角色完毕后，技艺最高等级为9。

提升 技能· 武艺： 消耗 [目标等级x1] 点造化，进行长达 [目标等级 x 月] 的练习，来让某项武艺提升1级。在创建角色完毕后，武艺最高等级为9。

提升属性： 消耗 [目标等级x3] 点造化，进行长达 [目标等级 x 年] 的锻炼，来让某项属性提升1级。不能超过该属性的【天生上限】。不能提高魅力属性。

修习内功心法： 消耗 [心法等级x2] 点造化，进行长达 [心法等级 x 半年] 的锻炼来修习一个新的内功心法。内功招式的修习数最多等于你的根骨属性，你也无法抛弃已修习的内功心法。

修习外功招式： 消耗 [招式等级x1] 点造化，进行长达 [招式等级 x 10天] 的锻炼来修习一个新的外功招式。外功招式的修习数无限。

重训功法： 消耗 [2] 点造化，消耗与修习这个功法相同的时间，来重新选择【正练】、【逆练】、【冲解】。

注：若GM与玩家们更想要一场属于青少年英豪的江湖故事，大可将上述修行时间减半，甚至除以四。

例：商想要把自己的剑法从5级提升至7级。于是他先要将剑法提升至6级，目标等级为6，消耗6点造化和6个月的时间；接下来他的目标等级为7，消耗7点造化和7个月。最终合计为13点造化和一年零一个月。

欧阳想要把自己的弈棋从5级提升至9级。于是他先要将弈棋提升至6级，目标等级为6，消耗2点造化和6个月的时间；接下来他的目标等级为7，消耗4点造化和14个月；以此类推，提升至8级需要4造化16个月，提升至9级需要4造化18个月。最终，消耗14点造化，经过四年半的闭关修炼，欧阳终于得到了9级的顶级棋术，放眼世间已鲜有敌手。

奇遇增效

除去按部就班地勤学苦练，江湖中总有着各式各样的奇遇来让角色们在短时间内提升自己的功力，无论是偶然遇到的世外高人，还是秘密获得的真传秘籍，这些都能为角色提供【奇遇增效】。

一般地，奇遇增效仅能让角色更快地获取内外功法，而非提升技能与属性等级。根据奇遇的内容，GM应酌情降低修习功法所需的造化和时间，至多降低至一半。

本质上，奇遇增效是在给玩家们提供额外的造化，故GM也应当保持上述原则，即所有玩家在冒险中获得的造化差在20%以内。例如，GM在为一名玩家提供秘籍作为增效时，也应当对应地给其他玩家安排一位强大的师傅，以提供近似的增效。
