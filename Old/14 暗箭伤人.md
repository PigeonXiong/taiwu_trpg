# 暗箭伤人

暗器规则

准备暗器： 角色能在背包中携带任意多的暗器，但是只有【 准备 】了的暗器才能使用。角色至多能准备 [灵敏] 件暗器。此外，暗器也会如同其他物品一样受到角色负重的限制。

准备新的暗器、更换准备的暗器都只能在短休或长休中进行，角色需要进行如下常规检定：

[悟性 + 武艺·暗器等级 + 其他调整] 记录得到的成功数

每获得1个成功，角色便能准备一件暗器。角色也能保留一定的成功数，用来提高暗器的【隐匿度】。当角色完成了准备后，他所携带的暗器隐匿度记为 [成功数 - 准备好的暗器件数 + 1] 。

察觉暗器： 当一个准备了至少1件暗器的角色进入战斗后，他的所有对手进行【固有检定 ·

洞察】，阈值为该角色的暗器隐匿度。若成功，则观察者能够意识到此人准备了暗器，每个净成功还能让观察者随机了解到其中一件暗器的名字与效果。

暗器攻击： 暗器和常规武器类似，需要以普通攻击发动。使用暗器并不需要【持用】它，只要按照上述规则进行了准备即可。每进行1次暗器普通攻击，所用的暗器就要消耗1发弹药。

这需要【复合动作 · 暗器攻击】，消耗10点先机，且不受攻击速度的影响。攻击者从准备的暗器中选择1件，再从暗器可用的式「 掷 \ 弹 \ 御 」中选择一个，对射程内的目标进行攻击检定：

[式决定的属性 + 武艺·暗器等级 + 其他调整] vs. 攻击类型对应的防御值

注：和常规武器的攻击一样，暗器攻击能造成伤害，且获得对应的式。暗器攻击可以变招。

使用暗器发动催破： 暗器和常规武器类似，能用来发动催破招式。只要招式需求的式为「 掷 \ 弹 \ 御 」（这包括了暗器招式和御射招式），角色就能以暗器来发动该招式。即，角色能用暗器施展御射类催破招式（对应针匣和机关），反之亦然。

施展时，选择1件准备好的暗器进行攻击，以该暗器的基础伤害作为该催破招式的武器伤害。并根据招式决定的攻击类型，进行攻击检定。成功命中后，暗器的特殊效果也会如常生效。

一般地，催破招式的每次攻击（无论有多少命中项），会消耗所选暗器的1发弹药。部分催破招式会消耗更多弹药，这由其描述决定。无论消耗了多少发弹药，特殊效果也只会生效一次。

暗器属性

射程： 暗器攻击与近战攻击（范围根据武器触及决定）、远程攻击（范围为所有威胁范围外的格子）不同，每种暗器有着各自的射程，并且只能攻击恰好在射程中的敌人（近战攻击能以-4减值攻击与触及范围相邻的敌人，暗器攻击与远程攻击则不行）。

格挡： 暗器无法被持用，也无法用来格挡。

可用的式： 暗器无论类别，可用的式总是「 掷 \ 弹 \ 御 」三者。

暗器伤害： 暗器的基础伤害。在成功命中后，最终伤害还要加上攻击检定中获得的净成功，并减去目标的护体或御气（破体破气值则能穿透敌人的抵抗）。

破体/破气： 暗器的基础破体、破气，若显示为“-”则表示为0/0。再加上角色当前运起的功法提供的破体、破气，即为最终值。

重量： 一件暗器的重量，以斤为单位。弹药的消耗并不会影响暗器的重量。

弹药： 一件暗器的弹药数量。一般地，每次单独的暗器攻击会消耗1发弹药，使用暗器的催破招式消耗的弹药数量则由招式决定。

特殊效果： 部分暗器附带有毒素等特殊效果 。

制作材料： 根据暗器可选的制作材料，调整其属性和重量。（暂不可用）
