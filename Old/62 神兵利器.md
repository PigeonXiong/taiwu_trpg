# 神兵利器

武器规则

目前仅为每种武器提供了一份数据，在游戏中，不同材质、不同品级的同类武器会有很大差异，将在对数据模型进行测试后，于V0.2中更新。虽然数据不变，但可以参考“ https://taiwu.huijiwiki.com/wiki/%E7%89%A9%E5%93%81%E4%B8%80%E8%A7%88 ”来为武器挑选名字。

武器属性

近战触及：【 短 】、【 中 】、【 长 】三种近战触及分别对应同个格子、相邻的格子、距离2格的格子。角色能以正常骰池攻击触及内的敌人，以骰池-4为代价攻击与触及范围相邻的敌人，例如短触及的武器能正常攻击距离为0格内的敌人，以-4减值攻击距离为1格的敌人；中触及的武器能正常攻击距离为1格的敌人，以-4减值攻击距离为0格或2格的敌人；长触及的武器能正常攻击距离为2格的敌人，以-4减值攻击距离为1格或3格的敌人（但持用长触及武器的角色的威胁范围不会因此而增加）。

某些武器视作同时拥有两项触及，例如拂尘拥有【短+中】触及，则可以正常攻击距离为0格或1格的敌人，以-4的减值攻击距离2格的敌人。

远程攻击： 乐器、针匣、弓可以远程攻击，其他武器则不行。

格挡： 仅在持用格挡为“可”的武器时，角色才能进行【反应 · 格挡】。

可用的式： 每种武器可用的式是有限的，有1~3种。

武器伤害： 武器的基础伤害，在成功命中后，最终伤害还要加上攻击检定中获得的净成功，并减去目标的护体或御气（破体破气值能穿透敌人的抵抗）。

破体/破气： 武器的基础破体、破气，若显示为“-”则表示为0/0。加上角色当前运起的功法提供的破体、破气，即为最终值。

重量： 武器的重量，以斤为单位。

攻击速度： 一般地，使用武器进行近战攻击需要复杂动作，攻速为0时会消耗10先机。部分武器能减少该动作的先机消耗，而另一些武器则会增加。攻击速度只会调整近战攻击，而不会影响远程攻击和以此武器施放的功法。

[10

+ 武器攻击速度 + 角色攻击速度] 为使用该武器进行近战攻击所消耗的先机。无论你的攻击速度为多少，这个值最低为 [6] ，最大为 [14] 。

特殊效果： 部分武器类别有特殊效果，这些效果对该类别的所有武器都适用。

轻便 ，当角色以轻便武器进行战斗，且手上没有持握其他非轻便武器时，他计算负重等级时，膂力视作比原本高1。

隐蔽 ，隐蔽的武器方便藏身，不会在交涉中引起目标的警觉。

双手 ，这类武器需要双手持用。（没有双手效果的武器则是单手武器）

非致命 ，这类武器即使是在死斗中造成的伤害也永远是非致命伤害。

变招(2)、变招(4)， 这类武器非常适合进行变招，变招时产生的骰池减值会对应地减少2点或4点。

制作材料： 根据武器可选的制作材料，调整其属性和重量。（暂不可用）

徒手： 当角色总能用没有持用武器的手进行【拳掌】或【指法】攻击，此时视作他的武器类型为徒手。

掌套： 角色可以穿戴掌套的手来进行【拳掌】或【指法】攻击。穿戴掌套的手可以被用来持握其他物品和武器，此时掌套会无法使用。

刀： 使用刀来进行【刀法】攻击。

剑： 使用剑来进行【剑法】攻击。

短杵： 使用短杵来进行【奇门】攻击。

对刺： 使用对刺来进行【奇门】攻击。对刺的对字，由来于大多数侠客喜好双手各持一把刺，实际上对刺并不属于双手武器。

棍： 使用棍来进行【长兵】攻击。

枪： 使用枪来进行【长兵】攻击。

拂尘： 使用拂尘来进行【软兵】攻击。

长鞭： 使用长鞭来进行【软兵】攻击。

瑶琴： 使用瑶琴来进行【乐器】攻击。瑶琴可以进行近战攻击或远程攻击，但只有前者能产生式。

萧笛： 使用萧笛来进行【乐器】攻击，但萧笛除了音式以外，还能使用点和拿式。使用音式攻击时，萧笛必须被双手持用，以人物的 [内息]

计算武器伤害；使用点和拿式时，萧笛可以单持也可以双持，以人物的 [膂力]

计算武器伤害。萧笛可以进行近战攻击或远程攻击，但只有前者能产生式。

针匣： 使用针匣来进行【御射】攻击。针匣可以进行近战攻击或远程攻击，但只有前者能产生式。一具针匣一般有20发弹药，这些弹药会在短休时自动补充。每次单独的武艺攻击或功法攻击，都会消耗1发弹药（部分催破招式会消耗更多弹药）。

机关： 使用机关来进行【御射】攻击。机关可以进行近战攻击或远程攻击，但只有前者能产生式。一具机关一般有20发弹药，这些弹药会在短休时自动补充。每次单独的武艺攻击或功法攻击，都会消耗1发弹药（部分催破招式会消耗更多弹药）。

弓： 使用弓来进行【御射】攻击。弓只能进行远程攻击，不能产生式，弓的攻击类型总是迅疾。

特别的，每张弓在制作完成后，它应当对应一个膂力值。例如一张对应膂力3的弓，膂力为3或更高的人都能正常使用它，但武器伤害固定为

[4+3=7] 点；而膂力为1的角色只能造成[4+1=5] 点武器伤害，且由于膂力不足而在命中上承受 [3-1=2] 点骰池惩罚。
