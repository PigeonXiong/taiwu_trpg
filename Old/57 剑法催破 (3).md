# 剑法催破

界青门催破招式

剑法催破

界青快剑

界青快剑收发迅疾，灵敏快密，足不停步，即走即刺，能于眨眼之间同时刺击敌人周身一十七处要害，快似凫趋雀跃，星流电击。

等级： 1

类型： 界青门 \ 催破 · 剑 法

属性： 玄阴

需求： 剑法1，灵敏2

运功效果：

迅疾 类攻击 骰池+1 。你能用迅捷来拔刀（通常，拔刀是简单动作）。

施展： 复杂动作，10先机

消耗： 2架势，1 刺 式

触及： +0

目标： 单体

伤害： 武器伤害+0d6，无额外破体破气

内伤发挥： -2

施展效果：

特别的，本招式不需求仪式动作，而需求复杂动作，其消耗的先机也会受到攻击速度的影响。你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中多少项不会额外造成伤害。命中至少一项时，你获得一个「杀机」；命中三项时，对目标造成一个破绽。

心法正练：施展本招式且命中后，进行一次

[悟性 +

剑法] 简单检定，至少得到2个成功时，你能无消耗地对同个目标再施展一次本招式。此效果可以连续触发，且每次若命中都能产生「杀机」，但触发所需的成功数逐次增加2点。

心法逆练：本招式如常需要仪式动作，且不再受攻击速度影响。本招式的施展完毕后，能进行连续的三次 力道 + 迅疾 + 精妙 的复合攻击，取代通常的一次，且每次命中都如常根据命中多少项来计算伤害、产生「杀机」和破绽。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的骰池加值再+1，且能用迅捷来收刀（通常，收刀是简单动作），且匿刀藏剑的间隔降低1轮（详见元山派说明）。

绝义剑

界青门人擅使绝义剑，此剑法虽然招式平平无奇，但出则共伤，发则同戮，施展开来，尽是同生共死的搏命招术，尤为江湖人士所畏惧。

等级： 2

类型： 界青门 \ 催破 · 剑 法 \ 仪式

属性： 玄阴

需求： 剑法2，灵敏3

运功效果：

迅疾 类攻击 骰池+2 。

施展： 仪式动作，10先机

消耗： 1架势，1提气，2 刺 式

触及： +1

目标： 单体

伤害： 武器伤害+2~4d6，额外破体2

内伤发挥： 0

施展效果：

你进行一次 力道 + 迅疾 的复合「剑法」攻击。命中一项 额外 造成2d6伤害。

心法正练：施展本招式时，你能额外消耗2个「杀机」，本招式的最终伤害+3d6。

心法逆练：本招式的最终伤害+3d6，但你也会受到伤害值一半的伤害，反噬的伤害不计算穿透与抵抗。

心法冲解：净成功能造成额外伤害，命中后总伤害再+1d6。运功提供的骰池加值再+1。

咸池剑气

“天潢南三星曰咸池，鱼囿也，动则道不通，天下败乱”。咸池剑气乃灾厄之气，尤其凶煞险恶，中者内气闭塞，真气逆乱，精神破败而死。

等级： 3

类型： 界青门 \ 催破 · 剑 法 \ 仪式

属性： 玄阴

需求： 剑法3，灵敏3，根骨2

运功效果：

迅疾 类攻击 骰池+3 。

施展： 仪式动作，9先机

消耗： 3提气，2 刺 式

触及： 无

目标： 距离在2~4格的单体敌人

伤害： 武器伤害+1~5d6，额外破气4

内伤发挥： +3

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 力道 额外 造成1d6伤害、命中 精妙 或 迅疾 额外 造成2d6伤害。

心法正练：施展本招式且三项攻击全部命中时，将目标现有的烈毒、赤毒、腐毒、幻毒毒素全部情况，并等量转化为寒毒毒素。

心法逆练：施展本招式且三项攻击全部命中时，记目标现有的寒毒毒素为X，清空寒毒，然后目标摄入烈毒、赤毒、腐毒、幻毒毒素各

[X/2] 点。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的骰池加值再+1。

界青暗手快剑

界青暗手快剑招式隐秘，讲究：“发不见刃，收不见血”，出剑无影无踪，快如疾风之超尘，电火之行空，能断人颈项而首级绝不跌落。

等级： 4

类型： 界青门 \ 催破 · 剑 法 \ 仪式

属性： 玄阴

需求： 剑法5，灵敏4

运功效果：

迅疾 类攻击 骰池+3 。 你能用迅捷来收刀（通常，收刀是简单动作）。

施展： 仪式动作，6先机

消耗： 2 架 势，1提气，3 刺 式

触及： +0

目标： 单体

伤害： 武器伤害+1~3d6，额外破体3

\ 破气2

内伤发挥： -1

施展效果：

你进行一次 迅疾 + 精妙 的复合「剑法」攻击。命中 精妙 额 外 造成1d6伤害，命中 迅疾 额外造成2d6伤害 。命中两项时，对目标造成一个破绽。

心法正练：施展本招式且两项攻击全部命中时，你能够立刻消耗1个「杀机」，并降低自己10点先机（可以降低至负值），来无消耗地施放一个「界青快剑」。你需要运起「界青快剑」才能使用这个效果。

心法逆练：本招式无法造成伤害和破绽，但每命中一项，你便能立刻无消耗地施放一个「界青快剑」。你需要运起「界青快剑」才能使用这个效果。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的骰池加值再+1，且你能用迅捷来拔刀（通常，拔刀是简单动作），且匿刀藏剑的间隔降低1轮（详见元山派说明）。

杀剑

杀剑凌厉狠恶，只攻不守，乃是有进无退，有死无生之绝命剑法。杀剑一起，运剑者必置生死于度外，敌死方收，至死方休。

等级： 5

类型： 界青门 \ 催破 · 剑 法 \ 仪式

属性： 玄阴

需求： 剑法5，灵敏3，定力3

运功效果：

迅疾 类攻击 骰池+4 。每场战斗开始时获得1个「杀机」。

施展： 仪式动作，8先机

消耗： 3 架 势，1提气，3 刺 式

触及： +1

目标： 单体

伤害： 武器伤害+1~7d6，额外破体4

\ 破气2

内伤发挥： -2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 力道 或 精妙 额外 造成1d6伤害、命中 迅疾 额外 造成5d6伤害。

心法正练：施展本招式且三项攻击全部命中时，你能消耗3个「杀机」，本招式的外伤伤害增加X，X等于目标外伤上限的一半。

心法逆练：施展本招式且三项攻击全部命中时，你能消耗3个「杀机」，本招式的内伤伤害增加X，X等于目标内伤上限的一半。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6。运功提供的骰池加值再+2。

幽冥剑法

幽冥剑法阴柔害物，幽藏晦暗，似出未出，未出已至，无可察觉，不可名状，有道是：“视之无形，听之无声，幽冥者，所以喻道而非道也”。

等级： 6

类型： 界青门 \ 催破 · 剑 法 \ 仪式

属性： 玄阴

需求： 剑法5，灵敏4，悟性3，根骨2

运功效果：

迅疾 类攻击 骰池+5。寒毒抵抗+5。

施展： 仪式动作，7先机

消耗： 1架势，3提气，4 刺 式

触及： +2

目标： 单体

伤害： 武器伤害+2~8d6，额外破体2

\ 破气6

内伤发挥： +2

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 力道 或 精妙 额外 造成2d6伤害、命中 迅疾 额外 造成4d6伤害。命中至少一项，目标摄入6点寒毒；命中至少两项时，对目标造成一个点穴。

心法正练：施展本招式且三项攻击全部命中时，目标获得异常状态：持续4轮，三个运起的「纯阳」或「金刚」功法无法使用，运功效果也无效。施展者可以选择让哪些功法无效。

心法逆练：施展本招式且三项攻击全部命中时，目标获得异常状态：持续4轮，三个运起的「紫霞」或「归元」功法无法使用，运功效果也无效。施展者可以选择让哪些功法无效。

心法冲解：净成功能造成额外伤害，命中后总伤害再+2d6。运功提供的骰池加值再+2。

无瑕七绝剑

所谓“无瑕七绝剑”，乃是一门断绝“喜、怒、忧、思、悲、恐、惊”以至行如傀偶，无思无想，从而臻至行剑无碍，剑力无瑕之用剑化境的秘传剑法。

等级： 7

类型： 界青门 \ 催破 · 剑法 \ 仪式

属性： 玄阴

需求： 剑法6，灵敏6，悟性3

运功效果：

迅疾 类攻击 骰池+6 。你能用迅捷来拔刀和收刀（通常，拔刀和收刀是简单动作），且匿刀藏剑的间隔降低1轮（详见元山派说明）。

施展： 仪式动作，7先机

消耗： 4 架 势，1提气，4 刺 式

触及： +3

目标： 单体

伤害： 武器伤害+7d6，额外破体7

\ 破气1

内伤发挥： -3

施展效果：

你进行一次 迅疾 「剑法」攻击。命中后额外造成7d6伤害。命中后对目标造成一个破绽。

心法正练：成功施展本招式后，你能消耗数值合计为7的数个「杀机」（例如杀机3+杀机4、两个杀机1+杀机5），本招式能无需检定自动命中（但净成功记为0），并且在本招式结算完成后，立刻无消耗地施展一个「界青暗手快剑」。你需要运起「界青暗手快剑」才能使用这个效果。本招式所引发的后续催破招式都能无需检定自动命中（但净成功记为0）。

心法逆练：成功施展本招式且命中后，你能消耗数个「杀机」，将这些杀机的数值合计记为X。在本招式结算完成后，立刻无消耗地对目标发起X次武艺攻击，无论X有多少，追加攻击的次数上限为7。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6。运功提供的骰池加值再+3。

玄冥剑气

玄冥剑气至阴至寒，凛冽惨切，剑气笼罩之处，呵气成霜，滴水成冰，似冰锥之刮骨，如厉风之穿心，当者立刻化为片片碎冰。

等级： 8

类型： 界青门 \ 催破 · 剑 法 \ 仪式

属性： 玄阴

需求： 剑法7，悟性5，根骨5

运功效果：

迅疾 类攻击 骰池+7 。剑法等级+1。

施展： 仪式动作，10先机

消耗： 5提气，4 刺 式

触及： 无

目标： 距离1~5格的单体敌人

伤害： 武器伤害+3~9d6，额外破气10

内伤发挥： +5

施展效果：

你进行一次 力道 + 迅疾 + 精妙 的复合「剑法」攻击。命中 任意一项额外 造成3d6伤害。命中至少一项使目标摄入12点寒毒。

心法正练：只要你在战斗中，所有敌人的寒毒抵抗视作无限。但记对方体内的寒毒毒素为X点。成功施展本招式且命中并使目标摄入毒素后，本招式的最终伤害增加

[X/3] d6。

心法逆练：只要你在战斗中，你的寒毒抵抗视作无限。但记你体内的寒毒毒素为X点。成功施展本招式且命中后，本招式的最终伤害增加

[X/2] d6。

心法冲解：净成功能造成额外伤害，命中后总伤害再+3d6，且剑法等级再+1。
