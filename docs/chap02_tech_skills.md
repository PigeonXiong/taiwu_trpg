# 技艺技能

三百六十行，行行出状元。除去武学上的造诣，角色在生活冒险中的方方面面所需要用到的技能，都被称呼为技艺，这囊括了原作中的十六种技艺，以及一部分七元赋性和一些在桌面规则中常用的技能。

技艺技能根据使用场景，会关联一项或多项属性（六维属性和魅力属性），进行检定时，默认使用：

!!! formula ""
    `[关联属性等级 + 技艺等级 + 其他调整] vs. [阈值]`
    
    技艺根据使用场景会关联不同的属性。关联多项属性时，检定者可自行选择较高的属性。


特别的，当技艺等级为`0`时，视为 **【未受训】** ，部分未受训的技艺也可尝试检定，但会受到`-2`减值，使用：

!!! formula ""
    `[关联属性等级 - 2 + 其他调整] vs. [阈值]`


## 技艺列表

技艺分为：


制造技艺： 巧匠、织锦、锻造、制木、厨艺

医学技艺： 医术、毒术

冒险技艺： 勇壮、搜查、杂学、交涉、术数

文化技艺： 品鉴、音律、书画、道法、佛学、弈棋


## 技艺详述

与武艺不同，某些技艺即使是未受训练的门外汉也能尝试几手，而另一些技艺则完全无法由未经训练者使用。每项技艺会标注其是否 **【未受训可用】** ：未受训可用的技艺在等级为0时仍可尝试检定；未受训不可用的技艺，至少需要学过1级才能使用。

### 医术 未受训可用

* 战外治疗：角色能用医术治疗自己和他人。每次短休或长休时，角色都能尝试一次医术常规检定：

!!! formula ""
    `[悟性 + 医术等级 + 其他调整] vs 0`

若角色获得 `N` 个成功，本次休息中，他和所有队友的每个回复骰效果变为 `N` 倍：短休从 `1D6` 提升为 `ND6`，长休从 `2D6` 提升为 `2ND6`。若角色已经耗尽当日的回复骰，则医术无法生效。

当多个角色同时尝试医术时，他们应当进行协助。由骰池较低者先进行检定，再将成功数加至骰池较高者的骰池中，进行最终检定。

* 战中治疗：角色能在战斗中进行上述检定，消耗 **【复合动作·15先机】** ，目标为自己或相邻的友军。每个成功只能恢复1点内伤或外伤。

角色在战斗中疗伤的次数有限，为 `[医术等级/3]`，向上取整。也就是说，医术等级为0的角色无法在战斗中尝试治疗。部分功法能增加战中治疗的效果和次数，或加快施展动作。

* 调查伤患：角色

* 望闻问切：除去武功较量时承受的伤势，江湖人士也会受到各类疑难杂症的影响。顽疾、旧伤、肢体残毁等问题无法通短休、长休以及普通的治疗解决。要治疗这类伤病，需要患者与医生共同配合，在休整期中进行治疗。医生每次过月都能进行一次医术常规检定，累计获得的成功，当成功数超过伤病对应的阈值时，治疗的第一阶段完成（如疾病不再恶化，旧伤不再发作等），并清空所累积的成功数。在这之后，医生可继续进行检定，当成功数再次累积至对应阈值时，治疗彻底完成（如疾病被治愈，旧伤被彻底祛除）。

### 毒术 未受训不可用

战外驱毒：角色能用毒术来弱化或驱除自己和他人体内的毒素（蛊虫、顽毒无法以此祛除）。每次短休或长休时，角色都能尝试一次毒术常规检定：

!!! formula ""
    `[悟性 + 毒术等级 + 其他调整] vs. [中毒]`

当角色身重多种毒素时，应取其中等级最高者作为阈值，再额外加上总毒素种类-1。例如，为一名身中3级烈毒，2级郁毒，1级寒毒的角色祛毒，需要3+2=5阈值

当成功数恰好等于阈值时，你就能选择目标体内一种毒素减益，使其降低1级。在这之后，每个额外成功，就能再选择目标体内的一种毒素降低1级。

每次该检定都会消耗1个患者的恢复骰。只要患者的恢复骰足够，就能连续多次祛毒。只要患者没有摄入新的毒物，每次成功的战外驱毒都能让你下次对该患者进行战外驱毒时的阈值-1，最低降至原阈值的一半，向上取整。

每天，单个治疗者对单个患者只能尝试一次战外驱毒。当多个治疗者想同时驱毒时，他们可以选择协助以攻克高级毒物，也可以各自尝试以快速驱除毒素。

战中抑毒：当你或威胁范围内的队友通过某种方式摄入毒物，并且被你察觉到时，你能消耗 **【反应动作·10先机】** 进行如下常规检定：

!!! formula ""
    `[灵敏 + 毒术等级 + 其他调整] vs. [毒物等级]`

当成功数恰好等于毒药等级时，你能辨认出目标毒物的名称和效果，并将毒物的 **【生效时间】** 推迟1档。此外，每获得1个净成功，你能选择下列一项：

1. 让毒物生效时间进一步推迟1档。
2. 选择该毒物具备的一种毒素，降低1点。

下毒：使用毒物之前，下毒者要先进行准备。无论是事先将毒物涂抹于武器上、制成药霜在战斗中使用，还是将毒物藏入目标的餐饮中，都需要进行如下常规检定：

!!! formula ""
    `[定力 + 毒术等级 + 其他调整] vs. [毒物等级]`

当成功数大于等于毒物等级时，你便成功施展目标毒物。涂抹于武器上或制作成药霜时，仍需要击中敌人才会让毒物生效；藏入餐饮后，仍需等待目标服下。此外，你每获得1个成功，还能选择提升毒物的部分效果。

角色也能尝试在同一把武器上淬上多种毒物，或在同一份餐食里添加多种毒物，甚至添加同一种毒物的多份剂量。这样做时，上述检定对抗的阈值提升为所有毒物的等级之和。合并毒物时，角色需要选取其中一种作为核心，最终毒物的隐匿度、发作时间、摄入方式、特殊效果将与核心毒物相同，其余毒物会将其蕴含的毒素添加至核心毒物中。

### 勇壮 未受训可用

户外行动：当角色在冒险中遭遇需要游泳、攀爬、谨慎走过独木桥等场景时，GM应根据环境的险峻程度设置阈值，并要求角色执行如下常规检定：

!!! formula ""
    `[灵敏 + 勇壮等级 + 其他调整] vs. [环境阈值]`

为避免角色们在冒险过程中意外分离，他们能够作为团队合作渡过难关。这样做时，只需大于等于团队人数一半的人完成任务，整个团队就能安全通过；若完成任务的人数不足，整个团队都将失败。

搬运重物：角色能临时搬起超过重载上限的物品，包括将重物举过头顶、短途搬运等行动。要开始搬运，角色需要空出两只手；若只空出一只手也能搬运，但检定需双骰取低。

!!! formula ""
    `[膂力 + 勇壮等级 + 其他调整]`

每点成功临时提高30斤负重。该检定也能用于角色间比拼膂力，各自进行搬运检定，再比较总负重上限，较高者获胜。

若要在战斗中搬运超过自己重载上限的物品，角色需要以 **【复杂动作·10先机】** 举起物品。举起物品后，角色无法进行常规行动和移动，只能以 **【复合动作·15先机】** 缓慢移动。搬运中的角色也能正常使用反应，但三项防御值都-2。

抵抗疲劳：每当角色没能完成长休地度过一整天，就要进行如下检定，阈值为累积的未长休天数。失败则会进入疲劳状态；若在疲劳状态下再次失败，则会力竭。

!!! formula ""
    `[体魄 + 勇壮等级 + 其他调整] vs. [未长休天数]`

闭气：角色能用勇壮来尝试闭气。无论是溺水、被捂住口鼻等被动情形，还是潜水、屏息抵御毒气等主动情形，角色都能无需动作地执行闭气检定。当角色能正常换气

!!! formula ""
    `[体魄 + 勇壮等级 + 其他调整]`

角色能不受影响地闭气一分钟，战斗内约10轮。闭气检定中每个成功能延长15秒，战斗内约3轮。在这之后，每过5秒，战斗内约1轮，角色就要受到 `2D6` 点无法抵抗的内伤，直到正常呼吸为止。

### 搜查 未受训可用

寻找事物：角色能在冒险中寻找被藏起来的物品、密门等事物。GM应当根据事物的隐藏度决定阈值，搜查者进行如下常规检定：

!!! formula ""
    `[悟性 + 搜查等级 + 其他调整] vs. [设定的阈值]`

若PC在游戏中提出合理且可行的搜索方向，应当适当降低阈值。

追踪痕迹：角色能用搜查寻找他人留下的痕迹，这包括脚印、血迹、打斗遗留等物理痕迹，也包括目击证言、坊间流传的行踪等残留信息。搜查者进行如下常规检定：

!!! formula ""
    `[悟性 + 搜查等级 + 其他调整] vs. [设定的阈值]`

GM可以参考下表决定痕迹的阈值：

| 踪迹出现的时间 | 追踪阈值 |
| -------------- | -------- |
| 同一天数小时内 | 1        |
| 数日以内       | 2        |
| 一月至两月以内 | 3        |
| 半年左右       | 4        |

| 调整项                             | 阈值调整 |
| ---------------------------------- | -------- |
| 目标人数较多                       | -1       |
| 有大量目标外的人员经过             | +1       |
| 目标有明显特征，如独特体型、衣着等 | -1       |
| 目标的身法等级较高                 | +0~+2    |

### 杂学

**未受训可用。**

打探流言：角色能在特定区域打探潜藏的信息，这包括与居民交涉、搜索相关地点等所有尝试。根据消息的隐秘度，其需要的成功数不同。GM可以在消息列表中随机选择，也可以根据PC们的倾向来发布消息。

!!! formula ""
    `[魅力 + 杂学等级 + 其他调整]`

地方知识：角色能通过杂学获取当地知识，包括当地常用语、非法店家的位置、隐秘帮派所在等。该技能同样用于在伪装潜入一些当地集会时，做出得体且符合身份的言行。GM应当根据任务难度决定阈值，并让角色进行如下常规检定：

!!! formula ""
    `[悟性 + 杂学等级 + 其他调整] vs. [设定的阈值]`

### 交涉

**未受训可用。**

改变印象：暂缺。

说服他人：行走江湖，总不会只有打打杀杀。当角色需要以言语达成目的时，应当使用这项技艺。玩家应当以自己角色的口吻阐述交涉内容，而非直接提出交涉目的；GM也应降低说服阈值，以奖励恰当的扮演。

一般而言，战斗外的说服代表角色长时间交涉的最终结果，故不可重试；而战斗内的交涉没有限制，但每次使用都需要一个 **【复杂动作·10先机】** 。

!!! formula ""
    `[魅力 + 交涉等级 + 其他调整] vs. [设定的阈值]`

若角色交涉的内容并非事实，则他需要分配一定数量的成功来掩盖谎言。GM需为受骗方暗骰 **【固有检定·洞察】** ，并记录获得的成功。若唬骗方用来掩盖谎言的成功大于等于受骗方洞察的成功，则谎言并未被识破，唬骗方只能用剩余成功去对抗说服阈值；若掩盖谎言的成功小于洞察成功，则谎言被识破，但这并不等价于交涉失败。

### 武学

**未受训可用。**

观察对手：角色总能以武学观察对手的来路与擅长武学，帮助自己在战斗中做出更具针对性的决策。战斗前，角色一般有一次使用该技艺的机会；在战斗中观察对手的次数不限，但每次观察都需要一个 **【复杂动作·10先机】** 。

!!! formula ""
    `[悟性 + 武学等级 + 其他调整]`

角色能消耗对应的成功数，向GM索取各种信息：

| 观察项目                   | 所需成功 |
| -------------------------- | -------- |
| 三项攻击中最擅长的一项     | 1        |
| 三项攻击由高到低的顺序     | 2        |
| 三项防御中最薄弱的一项     | 1        |
| 三项防御由高到低的顺序     | 2        |
| 运起的功法主要出自什么门派 | 1        |
| 最擅长的武器类型           | 1        |
| 内伤、外伤哪项更低         | 1        |
| 有无运起护体绝技           | 1        |
| 运起的护体绝技具体列表     | 2        |

辨识招式：GM可以隐藏敌人所施放的催破招式名称和效果，转而以“一招凌厉的剑法”“一套变幻莫测的掌法”来指代。PC能够以武学辨识敌人的招式，从而得知其真实效果。辨识招式不需要动作，当对方施展时，进行如下常规检定：

!!! formula ""
    `[悟性 + 武学等级 + 其他调整] vs. [目标招式等级/2]`

目标招式等级除以2时向上取整。此项规则是可选规则，GM和玩家也能互相公开所用招式的名称和效果。

看破与协助：角色能在战斗中使用武学看破敌人的招式，以增加自己的三项防御值，或协助友军战斗。详见“战斗规则”章节。

取代需求：武学等级能够取代其他武艺技能，满足功法的修习需求，但不能取代属性需求。使用功法、执行检定时，不能使用武学等级代替对应武艺。例如，少林派的「罗汉功」修习需求为内功2、体魄2、定力2，则内功0、武学2、体魄2、定力2的角色也能修习它。

如果功法有复数武艺需求，则武学只能取代其中一个。

### 文化类技艺

**未受训不可用。**

品鉴、音律、书画、道法、佛学、弈棋、术数等文化类技艺，主要用于满足功法要求和角色之间比拼文化。比拼时，使用如下检定，成功数较高者获胜：

!!! formula ""
    `[悟性 + 文化类技艺等级 + 其他调整]`
