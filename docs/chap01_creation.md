# 角色创建

创建角色时，请严格按照下述步骤依次进行。本章默认创造 **【精纯等级】** 为1的初级角色，更高级的角色创建详见 [角色提升](chap01_leveling.md)。

下述步骤不能打乱，因为靠前的步骤可能会影响后续步骤，如部分特质会影响角色的魅力、出身会影响角色六维等等。

| 步骤   | 内容           | 主要事项                                     |
| ------ | -------------- | -------------------------------------------- |
| 第一步 | 构建角色形象   | 确定角色的【出身】和【处事立场】             |
| 第二步 | 选择特质       | 获得并花费【造化】，选择正面或负面【特质】   |
| 第三步 | 提升属性与技能 | 提升【六维】基本属性、【魅力】和各项【技能】 |
| 第四步 | 修习门派功法   | 分配门派支持度，习得对应功法                 |
| 第五步 | 购买初始物品   | 购买初始武器、护具与各类消耗品               |
| 第六步 | 完成人物卡     | 使用剩余【造化】、【运起】功法、编写背景     |

## 第一步：初入江湖

* 选择一项 **【处事立场】** ：刚正、仁善、中庸、叛逆、唯我。
  
一般而言，处事立场主要用于扮演，仅有少数功法的效果会受到处事立场影响。若角色长期做出违背处事立场的行为，GM有权让其处事立场发生偏移，并为其累加 **【入魔值】** 。详见“立场与入魔”章节。

* 再依据[角色出身表](chap01_origin.md)，选择一项 **【出身】** 。这由太吾绘卷中的志向转换而来，会调整角色的初始六维属性、初始技能，并提供一项特殊能力。




## 第二步：选择特质

你获得 `10` 点 **【造化】** ，用于选择 **【特质】** 。正面特质会消耗造化，负面特质会返还造化。

在这一步中，你选择的正面特质合计不能超过 `10` 点造化，选择的负面特质合计也不能超过 `10` 点造化。特质列表详见“人物特质”章节。

剩余造化仅可在第六步中继续使用。

!!! example ""
    例如，你选择了合计10点的负面特质，且没有选择任何正面特质，那么你将有20点造化可在之后使用。

    若你选择了合计8点的正面特质、2点负面特质，那么你将剩余4点造化可在之后使用。


## 第三步：提升属性和技能

### 提升属性

角色拥有六维 **【基本属性】** ，以及一项额外属性 **【魅力】** 。

| 属性 | 说明                                                                   |
| ---- | ---------------------------------------------------------------------- |
| 膂力 | 力量、肌肉强度、爆发力。影响力道、卸力、人物负重等。                   |
| 灵敏 | 灵活度、反应速度、协调力。影响迅疾、闪避、移动速度等。                 |
| 体魄 | 强健度、抵抗力、忍耐力。影响破体、破气、服食效果等。                   |
| 定力 | 心地清净、意志力、判断力、抓住良机的能力。影响动心、守心、战斗先机等。 |
| 根骨 | 先天素质、骨血品质。影响御体、御气、辅运内功数量等。                   |
| 悟性 | 智力、理解力、创造力、记忆力。影响精妙、拆招、许多技艺技能等。         |
| 魅力 | 外表、口才、影响他人的能力。影响许多技艺技能、部分功法效果等。         |

* 首先，投掷 `1D6` ，骰子出目即为你的初始魅力。
* 随后，你有 `15` 点属性点，可以分配到六维基本属性上；若你愿意，也可以用属性点提高魅力。
* 在这一步结束时，未使用的属性点将被浪费。

6项基本属性的初始等级均为 `1` ，创建角色时最高只能提高到 `5` ，记作 `1/5`。这一上限被称作 **【天生上限】** ，**出身**和**特质**会提高或降低初始值和**天生上限**。

在冒险过程中随着角色**精纯**的提高，属性的基础值会得到增长，但仍无法超过**天生上限**；内功心法、外功招式、物品等提供的额外属性加值，可以无视这一上限。但最终，无论通过何种方式，人物的属性都不能超过 `9` 。

与六维基本属性不同，魅力的天生上限总是 `9` ，但创建角色完成后不能随精纯升级提高；部分功法和物品可以提高魅力。同样，基础值与额外加成相加后的最终魅力也不能超过 `9` 。


!!! note "创建顺序"
    由于部分特质会影响魅力，所以你需要先选择特质，再投掷魅力。此外，你也必须在投掷完魅力后，再开始分配属性点。

### 提升技能

**【技能】** 分为 **【武艺】** 和 **【技艺】** 。详见[武艺技能](chap02_tech_skills.md)、[技艺技能](chap02_tech_skills.md)。

* 你有 `20` 点技能点，可以分配到所有武艺和技艺上。
* 在这一步结束时，未使用的技能点将被浪费。

所有武艺和技艺的初始等级均为 `0` ，代表无品级、未受训；创建角色时最高只能提高到 `5` ，记作 `0/5`。**出身**和**特质**会提高或降低初始值和创建时的上限。

与属性不同，技能没有**天生上限**。虽然创建角色时无法提高至`5`级以上，但你总能在冒险中随着精纯的提高，将它们学习至最高的`9`级。

此外，内功心法、外功招式、物品也可能提供额外的技能加值。与属性不同，基础值与额外加成相加后的最终技能等级可以达到 `10` 或更高。


## 第四步：修习门派功法

* 你获得 `4` 点 **【门派支持】** ，将它分配至所有十五门派上。

**门派支持**需按整数分配给所有十五门派，角色在单个门派拥有的支持度为`0~9`。当角色拥有`N`点支持度时，他可以习得该门派所有等级`N`或更低的 **「内功」、「身法」、「绝技」、「催破」** 功法。


!!! note "修习与运功"
    习得的功法在**运起**之前并不生效。即使角色拥有足够的支持度并习得了大量功法，他仍然受到精纯等级的限制，只能**运起**一定数量、一定品级的功法。详见 [角色提升](chap01_leveling.md)和战斗章节。

!!! note "门派身份"
    高门派支持并不意味着角色一定是这些门派的弟子。这可能代表父母的言传身教、高人指点，或偶然寻得门派秘籍。你也无需满足该门派对于弟子的特殊要求，例如少林寺不收女性弟子、璇女派不收男性弟子等。若需要扮演门派弟子，应当选择 **「门派修行」** 特质。


## 第五步：购买物品

在当前版本中，创建角色时使用简化购物。你可以直接选择下列物品：

1. 2把任意种类武器。
2. 1件任意身体护具。
3. 2件任意2级以下的消耗品。

## 第六步：完成人物卡

1. 使用剩余的**造化**进一步提升人物，你可以：
    * 以3点**造化**提升1级六维属性或魅力（不超过**天生上限**）
    * 以2点**造化**提升1级武艺技能（不超过创建上限）
    * 以1点**造化**提升1级技艺技能（不超过创建上限）
2. 根据战斗章节，选择**运起**的功法
3. 为角色取名、编写背景故事、完善人物

在这一步结束后，未消耗的造化也会被浪费。
