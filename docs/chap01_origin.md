# 附：角色出身表

## 山人

> 心有长林丰草，甘为山林之士，清苦鄙陋何足忧，且为人间蓬蒿客……

属性提升：膂力提升为`2/6`

技艺提升：勇壮提升为`1/6`

特殊效果：山水难阻，你在野外进行的勇壮、搜查检定获得`+2`加值

## 猎户

> 走兽行我前，飞鸟戏我侧，林壑万物为我用，天宽地阔任我游……

属性提升：灵敏提升为`2/6`

技艺提升：搜查提升为`1/6`

特殊效果：驾驭野兽，每月一次，你能与野兽交流，尝试`搜查(野兽精纯/2)`检定，每有一个净成功，便可问一个问题

## 匠人

技艺提升：从巧匠、织锦、锻造、制木中任选一项，提升为`1/6`
